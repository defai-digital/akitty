# AkiTTY 1.3.8

- Fix local agent busy rejections losing their response when a client is still sending its request. Busy requests remain bounded and are never dispatched.
- Stabilize the PTY echo-latency regression check with an explicit readiness handshake and exact echoed-line checks.
- Include the typing, rendering, scrolling and memory improvements and backwards-compatible shifted snapshots from 1.3.6.

The native app supports macOS; AkiTTY Web provides the separate cross-platform browser terminal.
