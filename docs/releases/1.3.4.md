# AkiTTY 1.3.4

- Fix repeated event-log rotation for large admitted records with small segment limits. Retention markers use a bounded host session so the original event fits after one rotation, preserving its session, fields and sequence.
- Reject named pipes and other non-regular event files without waiting for a writer. Inspect event files using nonblocking opens so damaged storage cannot indefinitely stall event export or retention cleanup.
- Add regressions covering large payloads, long session identifiers, bounded rotation, valid JSONL exports and named-pipe rejection.

Apple Silicon, macOS 14+. This maintenance release preserves the existing native terminal, SDK and Web integration contracts. Ongoing experimental Linux and unrelated terminal work is not included. Agent reports remain unverified and every local command request still requires human approval.
