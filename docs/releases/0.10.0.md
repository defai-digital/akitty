# AkiTTY 0.10.0

Seamless box drawing, better CJK and emoji text, and a much broader Kitty graphics subset.

- Draw box-drawing, block-element and braille characters from cell geometry instead of
  font outlines, so `│ ┃ ├ ┼`, rounded and double lines, shades, quadrants and braille
  dots join across rows and columns without gaps. Text UIs such as AX Code's input box
  now render continuous borders.
- Fit CJK and other non-ASCII glyphs inside their one- or two-column box: they are
  centred and shrunk only when they would spill into the next row. Fallback fonts
  follow the system language, and Settings has a new CJK font picker that accepts any
  installed family.
- Draw ZWJ emoji sequences and flag pairs as one glyph while keeping `wcwidth` columns,
  which is what the terminal's grapheme-cluster mode (reported as unsupported) promises.
- Sound the terminal bell (at most once a second). BEL that terminates an OSC string is
  not treated as a bell.
- Kitty graphics: report window and cell pixel sizes (`TIOCGWINSZ`, `CSI 14 t`,
  `CSI 16 t`), accept PNG, honour image numbers, source rectangles, cell offsets and
  z layers, support every delete mode, free images that can no longer be named, and
  keep images attached to their text through scrolling regions, insert/delete lines,
  erases, resizes and a full scrollback. Programs that send frames without an image id
  (such as `mpv --vo=kitty`) no longer leak images until the budget is exhausted.
- Pin CJK, fullwidth, jamo, combining-mark and emoji cell widths with core tests.

Apple Silicon, macOS 14+. Developer ID signed and notarized, with signed Sparkle
updates served through Cloudflare R2. Still not implemented: Sixel, file and
shared-memory Kitty transfers, Unicode-placeholder images, Kitty animation frames and
grapheme-cluster width mode.
