# AkiTTY 1.2.2

- Keep Bash prompt-array hooks, including hooks added after startup, out of command records and run them once per prompt. Preserve the command exit status each array hook expects.
- Record subshell-only command lines through PS0 on Bash 4.4 and newer when they reach history. Bash 3.2–4.3 retains its documented limitation for these lines.
- Preserve user regular-expression captures in BASH_REMATCH across prompts and command hooks by parsing history without regular expressions.
- Expand shell-hook regression coverage and CI across system Bash 3.2, Linux Bash 5.1/5.2, and current Homebrew Bash.

Apple Silicon, macOS 14+. Developer ID signed and notarized, with signed Sparkle updates served through Cloudflare R2. AkiTTY Web remains a separate private source package.
