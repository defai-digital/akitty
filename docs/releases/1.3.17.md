# AkiTTY 1.3.17

Folder continuity, saved tab selection and program-status display fixes.

- New tabs keep the focused pane's starting folder when the shell has not reported a valid current directory. A tab opened with its own profile or default settings no longer inherits the window's unrelated starting folder.
- Restarting a terminal keeps that pane's starting folder when no valid shell directory report is available, including panes opened with their own profile or default settings.
- Reopening a layout with ten or more tabs restores a saved ninth-tab selection correctly. Command-9 still selects the last tab.
- Tab badges refresh when only program status changes, so working, blocked, error and done reports do not leave a stale badge or another pane's sprite visible.
