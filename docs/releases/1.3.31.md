# AkiTTY 1.3.31

## Improvements and fixes

- Preserve web-terminal scrollback content as new output arrives, including full history, smooth scrolling, nested writes and synchronized-output expiry. Explicit scrolling from an output callback now takes precedence over automatic preservation.
- Apply the default web-terminal background consistently and refresh cached links when synchronized output becomes visible.
- Rebuild native snapshot hyperlink tables before retained entries exhaust the bounded table, keeping links on visible cells usable. Apply the terminal reply bound to cell-size queries.
- Accept empty HTTP list items in download conditionals and byte ranges, while keeping strong validator requirements for If-Range.
- Refresh the committed WebAssembly engine's source and artifact provenance for this workspace version.

## Verification

- Reproduced callback scrolling being reset before the fix; regression tests cover immediate and synchronized output alongside nested writes, full history and smooth-scroll targets.
- The full release gate covers Rust, native ABI/PTY/Swift behavior, TypeScript, SDK and web browsers, rebuilt and committed WebAssembly, native traces, shell integration, installer/release tooling and public-file audits.
