# AkiTTY 1.3.20

## Fixes

- Redundant escape bytes before intercepted shell/status messages and Kitty graphics no longer swallow subsequent terminal output.
- Unicode grapheme clusters that widen at the final column respect disabled automatic wrapping.
- Images anchored on discarded rows no longer reappear after a terminal is shrunk and enlarged.
- Alternate-screen images follow retained rows during resize, while images on discarded rows are removed.
- Rebuilt the shared WebAssembly engine and refreshed its source provenance so browser terminals receive the engine fixes.

## Verification

- Added chunk-boundary, Unicode wrapping, and main/alternate-screen image-resize regressions.
- Verified with the canonical Rust, WASM, TypeScript, browser, Swift, ABI, shell-integration, installer and release-tooling checks.
