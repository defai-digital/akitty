# AkiTTY 1.3.19

## Fixes

- Shell exits close their pane for any reported exit status, including a bare `exit` after a failed command. Engine and PTY errors remain visible for restart.
- AkiTTY Web stops a wheel gesture when a custom handler closes or resets the terminal, preventing an exception or an unintended scroll in its replacement.

## Verification

- Added real-shell and native pane-close regressions for nonzero exits.
- Added Web regressions for disposal and reset during a custom wheel handler.
- Verified with the canonical Rust, WASM, TypeScript, browser, Swift, ABI, shell-integration, installer and release-tooling checks.
