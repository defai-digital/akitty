# AkiTTY 0.8.0

Kitty graphics, enhanced keyboard input, and verified terminal installation for macOS.

- Add a bounded Kitty graphics subset for direct RGB/RGBA images, zlib compression,
  chunked uploads, placement, layering and deletion. Pixel animations such as
  AX Code's opening and ending scenes can run in the native terminal.
- Harden graphics parsing against hostile output and bound image counts, sizes
  and decompression. Prevent image-ID collisions, preserve main-screen images
  across alternate-screen retransmission, and cancel partial uploads on screen changes.
- Implement all five Kitty keyboard flags, press/repeat/release events and modifier
  keys. Correct focus-loss releases and legacy F13–F20 sequences.
- Add a curl-downloadable installer that verifies the immutable release manifest,
  archive size and SHA-256, Developer ID signature and notarization before replacing
  an existing app. The default destination is `~/Applications`.
- Include the latest installer instructions and pnpm lock/configuration alongside
  the existing npm-based build and verification workflow.

Apple Silicon, macOS 14+. The macOS app uses Rust and Swift, with a bundled
TypeScript command palette. It is Developer ID signed and notarized; signed Sparkle
updates and installer downloads are served through Cloudflare R2.

The graphics subset does not support PNG/file-based transfers or sixel. Main-screen
image placements follow scrolling while scrollback grows; at a full or disabled
scrollback buffer, images stay on their viewport rows. Base-layout alternate keys
are reported for US-position keys. This remains an early release without full
Ghostty feature parity; see README and ABI documentation for compatibility limits.
