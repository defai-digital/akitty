# AkiTTY 0.12.1

This maintenance release fixes pane search, bounds renderer memory, and hardens terminal cleanup and release delivery.

- Keep search attached to its originating pane, restore focus when it closes, and clear old highlights when its target changes.
- Bound the renderer colour cache and release layer bitmaps after the final image disappears.
- Clear selections on plain clicks, reject late operations after session closure, validate program-chrome sprites, and require a window before confirming unsafe pastes.
- Ignore preference changes after terminal shutdown.
- Let AkiTTY Web refit after an external resize and remove all terminal and selection listeners on disposal.
- Handle weak and list ETags correctly in the download gateway without fetching unchanged bodies.
- Bind signed bundles to their clean source commit, prepare release assets atomically, validate manifests and update feeds, and allow safe retries of interrupted publication.
- Credit iTerm2 and Kitty as architecture references.

Apple Silicon, macOS 14+. Developer ID signed and notarized, with signed Sparkle updates served through Cloudflare R2.
