# AkiTTY 2.1.0

## Find in All Terminals

- Open **Edit → Find in All Terminals** (⌥⌘F) or search for the action in
  the command palette. Search retained output in **This Window** or
  **All Terminals**.
- Results are grouped by window and tab and show the pane, its reported
  folder when available, and a text snippet. Open a result to focus its pane
  and highlight the match. A result follows its pane when a tab moves.
  Expired matches and closed panes get a message.
- AkiTTY lists up to 32 hits per pane and 100 overall. It checks for
  another match before showing that results were capped.

## Terminal updates

- The VT engine carries ASCII classification through synchronized output so
  replay can reuse it. The bundled WebAssembly engine includes this change.
- Native rendering checks atlas eligibility on the raster queue, reuses
  cached font metrics, and reduces work when shifting existing glyph rows.
  A cursor that stays hidden no longer expands the damaged area.

The native app requires Apple Silicon and macOS 27.2 or later.
