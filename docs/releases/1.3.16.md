# AkiTTY 1.3.16

Named terminal profiles, colour themes, cursor styles and saved window layouts.

- Settings now includes named profiles for font, theme, cursor, shell, starting folder and scrollback. New windows, tabs and splits can use a profile.
- Save and reopen named arrangements of windows, tabs and splits from Shell → Window Layouts, including each pane's folder and profile. Reopening starts fresh shells.
- Saved layouts keep each pane's actual starting folder when no shell directory report is available, including tabs opened with their own settings or profile.
- Large saved split weights normalize without overflowing, preserving usable proportions.
- The OSC 52 clipboard prompt offers an Always Allow choice, also configurable in Settings.
- Agent request tools accept copied pane identifiers and explain rejected requests.
- Development scripts, download gateway and SDK tests use TypeScript with checked contracts.

## SDK 0.3.0 (published separately)

- `@defai-digital/akitty-sdk` validates input with [Zod](https://zod.dev) 4.6.7, its one runtime dependency, pinned exactly.
- New exports: `StatusSchema`, `MarkSchema`, `ProgressSchema`, `SpriteSchema`, `ChromeSchema` and `ChromePatchSchema` from the main entry; `ShellStateSchema` and `DispatchReceiptSchema` from `/host`.
- Invalid input still throws `RangeError` with the same messages; the Zod error is its `cause`. An object with an inherited enumerable property is now rejected as `unknown field`.
- The SDK is renamed from `@ax-code/akitty-sdk` to `@defai-digital/akitty-sdk` and is published to GitHub Packages when an `sdk-vX.Y.Z` tag is pushed. Imports must use the new name.
