# AkiTTY 1.0.0

AkiTTY 1.0 brings together the native macOS terminal, program integration SDK, and stability fixes for the separate AkiTTY Web terminal.

- Show each terminal program's title, status, progress, and sprite activity in its tab. The typed JavaScript/TypeScript SDK writes these updates through standard terminal output.
- Maintain the Alacritty and VTE engine sources locally, with recovery and lifecycle conformance coverage.
- Preserve valid settings when preferences need recovery, and enable Apply only when settings change.
- Keep image animation state and cell-size changes visible to snapshot clients. Reject excess image fragments without rejecting unresolved placeholders at the supported limit.
- Request confirmation before pasting terminal control characters, while allowing ordinary tabs.
- Fix web selection and fractional scrollback rendering, bracketed paste protection, title and bell parsing across writes, buffer change notifications, event listener dispatch, and WASM key encoder cleanup.
- Serialize installer replacements, preserve the previous app on failure, and terminate correctly when interrupted.
- Verify Sparkle signing identity, archive signatures, and feed metadata before publication; serve the installer from the tagged source and handle download preconditions consistently.

Apple Silicon, macOS 14+. Developer ID signed and notarized, with signed Sparkle updates served through Cloudflare R2. AkiTTY Web remains a separate private source package. Shell integration and quick terminal remain planned features; see the roadmap for the compatibility scope.
