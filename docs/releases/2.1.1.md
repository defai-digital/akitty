# AkiTTY 2.1.1

- Reuse Metal coverage masks for eligible box-drawing, block and braille
  glyphs. These glyphs use the same cell geometry as the software renderer
  and reuse their masks across foreground colors and font styles.
- Keep Find in All Terminals responsive when reopening the panel with an
  existing query or changing its scope. The scan yields between chunks of
  retained output.

The native app requires Apple Silicon and macOS 27.2 or later.
