# AkiTTY 0.6.0

Native terminal essentials for macOS 14 and later on Apple Silicon.

- Rust terminal engine and PTY management, Swift/AppKit interface and a small
  TypeScript command palette. No Zig or libghostty dependency.
- Visible **+** button and **⌘T** for new tabs, split panes, clearer
  **cols × rows** status, and automatic pane/tab cleanup after a normal shell exit.
- Native **Settings…** for font, size, shell, starting directory, scrollback,
  Option-as-Alt and automatic update checks.
- Quiet, versioned update reminders in the titlebar. Updates use signed Sparkle
  feeds and archives served through Cloudflare R2; installation remains user-controlled.
- Metal presentation with tested software fallback, Unicode/IME, accessible
  terminal text, text clipboard approval, scrollback search and mouse reporting.

The app and archive are Developer ID signed and notarized. AkiTTY's code is MIT
licensed, and the README acknowledges Ghostty as the design/reference starting point.
Third-party components retain their own licenses.

This is an early release, not full Ghostty feature parity. Kitty graphics, sixel,
Ghostty config compatibility, shell integration and third-party extensions are not
included. The initial downloadable package targets Apple Silicon; Intel Mac builds
are not published in this release.
