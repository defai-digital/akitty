# AkiTTY 1.3.24

## Fixes and improvements

- Move a live tab into a new window by dragging above or below its tab bar, or drop it on another regular window's tab bar. The tab context menu also offers **Move Tab to New Window**.
- Tab movement preserves running shells, split panes, scrollback, profiles, split proportions, program activity and host control state. An empty destination starts no temporary shell; the empty source window closes after its tab is adopted.
- Escape, app deactivation, a removed drag source and rejected drops cancel safely. Quick-terminal transfers and transfers during dialogs or termination are disabled. Within-window reordering remains available.
- Fixed a focus regression when moving a split tab with Find open: the searched pane retains focus instead of input being redirected to the first pane.
- Reordering the selected tab and moving a background tab preserve the focused split, so typing continues in the same terminal.

## Verification

- Added regression coverage for live session and control identity, split layout, focus, callback and unread-bell ownership, last-tab moves, drag cancellation, rejected drops, stale sources and dialog/quick-terminal exclusions.
- A real PTY regression verifies that shell environment state survives a last-tab move and the shell continues accepting input. The Find focus regression reproduces the defect before the fix.
- Two additional regressions reproduce split-focus loss during reordering and background-tab transfers before the fixes.
- The complete verification gate covers Rust, WASM provenance, TypeScript, native ABI/PTY and Swift behavior, Web browser behavior, shell integration, installer/release tooling and public-file hygiene.
