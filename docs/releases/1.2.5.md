# AkiTTY 1.2.5

- Preserve Caps Lock and Num Lock modifiers for enhanced non-text Kitty keyboard events, including arrow/function keys, Escape, repeats, and releases. Text-key compatibility and legacy mode remain unchanged.
- Cancel superseded AkiTTY Web scrollbar fades when activity resumes or the fade direction changes, preventing an old animation from dimming or hiding an active scrollbar. Pending fades are also canceled during cleanup.
- Add native keyboard and scrollbar activity regressions. AkiTTY Web remains a separate private source package.

Apple Silicon, macOS 14+. Developer ID signed and notarized, with signed Sparkle updates served through Cloudflare R2.
