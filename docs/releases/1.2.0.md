# AkiTTY 1.2.0

- Add Agent Overview, available from the Window menu, command palette, and Option–Command–A. Inspect every pane, show a terminal, or reclaim control while keeping host control separate from unverified program and shell reports.
- Enable bundled bash/zsh shell integration by default for new terminals. Other shells continue to start normally; the setting can be disabled in preferences.
- Join existing bash-preexec hooks and preserve existing DEBUG traps instead of replacing them.
- Fix exit-status chaining between existing Bash prompt-array hooks, with a real interactive-shell regression test.

Apple Silicon, macOS 14+. Developer ID signed and notarized, with signed Sparkle updates served through Cloudflare R2. AkiTTY Web remains a separate private source package.
