# AkiTTY 1.3.18

Recover from removed starting folders and release Web add-on resources reliably.

- New tabs and restarted panes fall back to the profile's or Settings' validated starting folder when the pane's reported and original folders are no longer available. A new tab does not substitute the window's unrelated folder.
- Splits also recover when the window's original folder has been deleted.
- AkiTTY Web 0.6.6 disposes an add-on whose activation closes the terminal, releasing its listeners and other resources exactly once. AkiTTY Web remains a separate source package for embedding hosts.
