# AkiTTY 2.1.3

- Render eligible monochrome Unicode, including wide CJK, from the Metal glyph
  atlas. Cache single underlines and strikethrough on narrow cells.
- Let the glyph atlas resume after a large working set shrinks.
- Use PTY notifications for live output and pause raster work while a pane is
  hidden.
- Avoid unnecessary refreshes after repeated input or an expired global search
  result. Successful search reveals still refresh the pane immediately.

The native app requires Apple Silicon and macOS 27.2 or later.
