# AkiTTY 1.1.0

AkiTTY 1.1 adds opt-in shell and agent-host workflows, a persistent quick terminal,
and native drag-and-drop, while keeping each program's tab identity central.

- Enable local bash/zsh shell integration in Settings to observe command boundaries,
  reported directories, timestamps and exit status, with bounded per-command output.
  User startup files are preserved; shell history stays outside signed app resources.
- Add exclusive agent control, exact-command one-shot approvals, native confirmation,
  human reclaim and a bounded session-local audit. SDK 0.2.0 exposes a separate typed
  host entry; the program-side title/status/sprite client remains independent.
- Toggle a persistent quick terminal from the Shell menu or a configurable global
  shortcut. Hiding keeps its sessions running; shortcut conflicts are reported.
- Drag local files/folders into a pane to insert shell-quoted paths, or drag text
  through ordinary paste protection. Agent ownership also blocks drops until reclaim.
- Use a deeper default background (#080A0D) consistently in the core and both render paths.
- Revoke Swift session access immediately when closing a pane, while PTY cleanup
  remains bounded and asynchronous. This fixes a shutdown scheduling race exposed by CI.
- Clarify program-supplied tab identity, read-only WebMCP, host responsibilities and
  actual macOS/Windows/Linux browser CI coverage.

Apple Silicon, macOS 14+. AkiTTY Web remains a separate private source package with
a host-owned PTY. Shell-reported command/output data is untrusted. Audit is bounded
and in-memory; authenticated ax-trust connectivity and durable organization-wide
records require an embedding host adapter. Remote/multiplexer workflows, physical
IME, accessibility and multi-day reliability retain their documented qualification limits.
