# AkiTTY 0.10.1

Corrections to the 0.10.0 text rendering.

- Draw the double-line tees and cross (`╠ ╣ ╦ ╩ ╬`) with open junctions. They were drawn
  as closed grids because every double arm ran across the whole cell.
- Keep narrow non-ASCII glyphs that sit off-centre (`Ⅲ`, `ℓ`, `Ί`) inside their cell instead
  of clipping their edge.
- Give ZWJ emoji sequences that begin with a narrow piece, such as the rainbow flag, a
  full two-column box so they are no longer drawn at half size.
- Let an explicit script tag outrank the region when choosing a CJK font, so `zh-Hans-HK`
  uses the Simplified face.

Apple Silicon, macOS 14+. Developer ID signed and notarized, with signed Sparkle
updates served through Cloudflare R2.
