# AkiTTY 0.9.0

Faster terminal updates, read-only agent access, and correctness fixes.

- Reduce native snapshot work by omitting default blank cells, decoding replies once,
  and transferring only changed rows while preserving a complete client snapshot.
- Improve AkiTTY Web's viewport reads, input encoding and render loop. Off-screen
  terminals continue parsing output while skipping drawing, with a full redraw on return.
- Add bounded, read-only terminal screen/output tools and optional WebMCP registration
  for the separate AkiTTY Web package. Terminal text is explicitly treated as untrusted data.
- Fix clipped output incorrectly reported as complete, and advance reader revisions
  after clear and resize so consumers can detect changes.
- Stop WebMCP registration after cancellation and remove external abort listeners
  on disposal instead of retaining registrations through a long-lived signal.
- Reject oversized native image dimensions before multiplication, preventing an
  integer-overflow crash in image-pixel reads.
- Include the README's project origin, AX Code Desktop connection and macOS focus.

Apple Silicon, macOS 14+. Developer ID signed and notarized, with signed Sparkle
updates served through Cloudflare R2. AkiTTY Web remains a separate private source
package; the native Mac app uses Rust and Swift with a bundled TypeScript palette.

The WebMCP adapter is optional and feature-detects browser support. Its tools are
read-only and do not send terminal input or run commands. Other compatibility
limits, including the bounded Kitty graphics subset, are documented in the README.
