# AkiTTY 0.7.0

Terminal correctness and macOS workflow improvements, plus AkiTTY Web source integration.

- Open folders from Finder, Dock drops, or `open -a Akitty <path>`. Files open in
  their containing folder; requests are bounded and skipped items are reported.
- Add F5–F12 terminal key sequences and correct click/drag selection behavior.
- Keep normal Copy/Paste editing in Settings and command-palette text fields.
- Preserve unrelated preferences when a saved shell or directory no longer exists.
- Improve contiguous command matching and bound Unicode palette queries.
- Prevent dropped terminal events during large output bursts, enforce the session
  cap during concurrent creation, and avoid viewport jumps when input is rejected.
- Integrate the separate AkiTTY Web canvas terminal source from AX Code Desktop,
  with pinned upstream provenance, MIT notices, type-checking and regression tests.
  The test environment uses the patched Happy DOM 21.0.4.
  Its prebuilt Ghostty WebAssembly parser is separate from the Rust/Swift Mac app.

The macOS package targets Apple Silicon on macOS 14+. It is Developer ID signed
and notarized; signed Sparkle updates are served through Cloudflare R2.
AkiTTY Web remains a private source package and is not published to npm.

AkiTTY is an early implementation, not full Ghostty feature parity. Kitty graphics,
sixel, Ghostty configuration compatibility, shell integration and third-party
extensions remain outside this release. See the README for compatibility scope.
