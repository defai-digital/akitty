# AkiTTY 1.3.28

## Improvements and fixes

- Soft terminal reset now makes a hidden cursor visible again and restores the default character sets, including cancelling a pending single shift. Applications recovering from DEC graphics mode can print ordinary letters correctly after reset. Existing screen contents and the current cursor position are preserved.
- Include the merged row-reset and CSI storage improvements: reset only conservatively tracked modified row prefixes when the blank background matches, rotate visible rows using a deque, retain bounded CSI parameter storage, and decode semicolon RGB parameters without a temporary vector. Background changes, resizing/reflow and untracked generation changes retain full resets. See [measurement scope and results](../PERFORMANCE.md).
- Rebuild the shared WebAssembly engine and refresh its source and artifact provenance.

## Verification

- Both soft-reset regressions failed before the fix. Native tests and shared native/WebAssembly fixtures cover cursor visibility, G0–G3 selection, single shifts, main/alternate screens, retained text and cursor position, including every byte split.
- The full release gate covers Rust, native ABI/PTY and Swift behavior, TypeScript/SDK/Web browsers, rebuilt and committed WASM, benchmark smoke, shell integration, installer/release tooling and public-file audits.

Protocol reference: [DEC soft terminal reset](https://vt100.net/docs/vt510-rm/DECSTR.html).
