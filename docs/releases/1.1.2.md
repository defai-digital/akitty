# AkiTTY 1.1.2

- Fix a rasterizer crash when a view shrinks while damage still refers to the previous grid, and safely clamp extreme input-method coordinates.
- Reject decoded PNG graphics whose frame dimensions disagree with their header.
- Preserve Caps Lock and Num Lock modifiers for functional keys in Kitty keyboard report-all-keys mode, including repeat and release events.
- Add randomized rasterizer coverage for drifting grid and view sizes.

Apple Silicon, macOS 14+. Developer ID signed and notarized, with signed Sparkle updates served through Cloudflare R2. AkiTTY Web remains a separate private source package.
