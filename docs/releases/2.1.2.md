# AkiTTY 2.1.2

- Validate only damaged rows for atlas eligibility on eligible no-scroll frames.
- Preserve pending redraw damage when snapshot and frame callbacks request
  a redraw while handling an earlier frame.
- Keep the existing Metal glyph atlas when unsupported content falls back
  to the software renderer at a different layout.

The native app requires Apple Silicon and macOS 27.2 or later.
