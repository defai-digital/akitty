# AkiTTY 2.3.2

- Fix keypad navigation in AkiTTY Web. With Num Lock off, keypad keys send
  navigation commands, and Kitty keyboard mode can distinguish them from the
  dedicated navigation keys.
- Keep supplementary-plane Unicode text printable in the Web keyboard encoder
  when an application requests Kitty escape-code disambiguation.

The native app requires Apple Silicon and macOS 27.2 or later.
