# AkiTTY 1.3.0

- Add OSC 7501 revision 0.4 program activity reports alongside OSC 771 sprites, including hierarchical state, progress, pane status and tab indicators. Program reports remain unverified presentation and cannot grant execution authority.
- Expand Agent Overview with separate program activity, host input ownership, shell state and local request availability, plus clearer VoiceOver labels and reclaim actions.
- Bundle `akitty-agent`, an opt-in, same-user local request client. Every command requires a native human approval sheet with Deny as default. Accepted commands receive one-shot host authorization; input stays leased until human reclaim or explicit host release. Ordinary agent subprocesses remain outside this path.
- Add a private, bounded event timeline and JSONL export with source labels, command hashes, rotation and loss markers. These local records are metadata, not verified results or tamper-proof attestations.
- Reject late approvals even when the main run loop delays timeout callbacks. Restore IPC availability after disabling and restarting a listener with an unfinished request; report busy requests as not dispatched and bound complete frame writes by an absolute deadline.
- Synchronize event directory entries as well as intent records before managed dispatch. Require timestamped Developer ID runtime signatures on every bundled Mach-O, including the new CLI helper, before notarization and release preparation.

Apple Silicon, macOS 14+. Developer ID signed and notarized, with signed Sparkle updates served through Cloudflare R2. No cloud account or AX product is required. Human reclaim returns terminal input; it does not stop a running process. Command policy adapters, independent execution evidence and remote PTY persistence remain future work.
