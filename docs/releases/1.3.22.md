# AkiTTY 1.3.22

## Fixes

- Cancelled native command requests no longer acquire terminal control or proceed from approval to authorization and dispatch. Cancellation during approval releases the lease without recording a human denial.
- AkiTTY Web stops processing a key when an `onKey` callback or custom key handler disposes the terminal, preventing input from being emitted after disposal.
- Build scripts consistently select Cargo and Clippy from the pinned rustup toolchain, preventing WASM checks from failing when same-version Homebrew tools use a different sysroot.

## Verification

- Added regressions for cancellation before command execution and during approval, including audit records and returned input ownership.
- Added regressions for disposal from both keyboard callback paths.
- Added a mixed-toolchain regression with competing Cargo and Clippy executables.
