# AkiTTY 1.3.30

## Improvements and fixes

- Fix ignored standalone eight-bit terminal controls: index, next line, tab-stop setting, reverse index, G2/G3 single shifts and terminal identification now use the same handlers as their seven-bit ESC forms. Bytes inside valid UTF-8 characters retain their text interpretation.
- Integrate benchmark qualification work with independent GPU-completion/presentation correlation, overlap and overflow regressions, burst scenes and expanded Unicode pixel-equivalence tests. The experimental Unicode bitmap-scroll optimization was rejected and reverted; the release retains the accepted renderer and refresh policy. [The qualification record](../PERFORMANCE.md#native-scroll-qualification-plan) documents the result and measurement limits.
- Rebuild the shared WebAssembly engine and refresh its source/artifact provenance. Shared native/WASM fixtures now support raw-byte protocol inputs.

## Verification

- Reproduced the missing eight-bit-control action before the fix. Native parser regressions and shared native/WebAssembly fixtures cover cursor motion, tab stops, single shifts, identification replies, UTF-8 continuation bytes and every byte split.
- The full release gate includes native trace correlation, Unicode raster comparisons, Rust/native ABI/PTY/Swift behavior, TypeScript/SDK/Web browsers, rebuilt and committed WASM, shell integration, installer/release tooling and public-file audits.

Protocol reference: [XTerm eight-bit control equivalents](https://invisible-island.net/xterm/ctlseqs/ctlseqs.html#h2-C1-_8-Bit_-Control-Characters).
