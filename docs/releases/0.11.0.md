# AkiTTY 0.11.0

This release brings together Kitty graphics, program status chrome, and more responsive terminal shutdown.

- Add Kitty animation, Unicode placeholders, relative placements, and bounded file and shared-memory transfers. Metal composites image textures separately from text and polls active animation at display rate.
- Let programs show bounded status text, progress, and a small sprite through OSC 771, with a native setting to disable program updates.
- Keep close and quit confirmations asynchronous, and bound child cleanup so late input and repeated shutdown requests remain responsive.
- Preserve the next frame's delay when deleting the first animation frame.
- Require the protocol marker in a temporary image's file name before consuming it, and recheck the opened path before reading or deleting it.
- Keep CJK font and program-chrome preferences together when saving settings.
- Reduce idle polling and row parsing in the separate AkiTTY Web terminal.

Apple Silicon, macOS 14+. Developer ID signed and notarized, with signed Sparkle updates served through Cloudflare R2.
