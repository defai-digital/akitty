# AkiTTY 2.0.0

## Review requests across panes

- Requests from several agents can wait in one approval queue. Each pane
  queues up to 8 requests, with a limit of 64 for the app. Queued requests
  expire after 120 seconds and leave terminal input under your control.
- Separate windows can show approval sheets at the same time. Agent
  Overview shows each pane's queue and how long its oldest request has waited.
- A request from another pane identifies that pane in the sheet.
  Use `akitty-agent request --id <id>` or the MCP `request_id` argument to
  name a request. Check its state with `akitty-agent status <id>` or the
  MCP `request_status` tool. Reusing an ID in the same app launch prevents
  duplicate dispatch.

## Set up Claude Code, Codex and AX Code

- Open **Settings → Agents** to see each CLI's location, version,
  integration status and most recent reported conversation. Local Agent
  Requests can be enabled at launch through an opt-in, accessible switch.
- Install Claude Code or Codex hooks to review supported Bash
  permission prompts in AkiTTY. The agent runs the command under its
  own policy. If AkiTTY cannot answer, the permission prompt stays with
  the agent.
- Connect AX Code through MCP. Its command requests join AkiTTY's approval
  queue, and the companion plugin reports which conversation is active.
  AkiTTY writes its entry to plain JSON and leaves `ax-code.jsonc` in place.
- Pending MCP approvals no longer block the Swift executor that handles
  other requests.
- Hook status now detects changed matchers and incomplete command settings.
  AX Code uninstallation checks the configuration before removing the
  conversation-reporting plugin.

## Reopen a workspace and resume a conversation

- Enable **Shell → Window Layouts → Reopen Windows and Agent Conversations
  at Launch** to save open panes and their reported Claude Code, Codex or
  AX Code conversation IDs. The workspace stores layout and conversation
  metadata only.
- A restored pane starts a fresh shell. Choose **Resume Agent Conversation**
  at an empty, idle prompt to resume the saved ID. Agent Overview confirms
  the resume after the same ID is reported by the agent in that pane.
- **Clear Saved Workspace** removes the saved layout and turns off restore.

The native app requires Apple Silicon and macOS 27.2 or later.
