# AkiTTY 1.4.0

- Improve terminal throughput for Unicode, long lines, and synchronized screen updates. The shared engine batches text and cell writes, and Apple Silicon builds use NEON to scan text chunks. See the [performance measurements and scope](../PERFORMANCE.md).
- Keep macOS terminal output flowing across PTY refill gaps, bound the final drain after exit, and retain the notification descriptor safely during close.
- Improve browser terminal reset handling for key, composition, mouse, and link callbacks. Keep complete UTF-8 characters when truncating terminal replies.
- Fix duplicate browser resize events and stale render notifications when a resize callback changes or resets the terminal.
- Refresh the bundled WebAssembly engine and its source provenance. The native application requires Apple Silicon and macOS 27.2 or later.
