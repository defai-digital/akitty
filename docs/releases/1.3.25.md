# AkiTTY 1.3.25

## Fixes

- Rejected shell-completion metadata no longer consumes a pending command's completion observation or adds a spurious completion event to the control audit. Valid completion notifications remain observable afterward. Shell observations remain untrusted and do not grant authorization or release host control.
- Shell directory notifications now enforce the documented 4 KiB limit on the complete URI, including its scheme and hostname. Oversized notifications preserve the last valid directory and increment the rejection counter.

## Verification

- Reproduced both defects before their fixes. Regression coverage checks oversized completion metadata, the exact URI byte boundary, and directory preservation through the native schema-1 API.
- The release gate covers Rust build/clippy/tests, native ABI and PTY behavior, Swift, TypeScript, Web browser behavior, WASM provenance, shell integration, installer/release tooling and public-file hygiene.
