# AkiTTY 1.4.1

- Reduce work when overwriting cells in the same truecolor style, and avoid a copy when the macOS host receives a core response.
- Keep retained glyph-atlas rows when scrolling can move them by an exact number of pixels. Re-encode damaged rows and recover fully after a discarded atlas update.
- Enable ThinLTO in the Rust static library shipped with the macOS app.
- Keep browser resize notifications current when callbacks resize or reset the terminal. Hosts receive the active grid size, and superseded frames stop emitting render notifications.
- Refresh the bundled WebAssembly engine and its source provenance. The native app requires Apple Silicon and macOS 27.2 or later.
