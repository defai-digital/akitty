# AkiTTY 1.3.6

- Reduce typing latency and idle PTY wakeups, and keep keyboard and mouse writes off the main thread.
- Reduce snapshot serialization contention and share graphics animation frame storage.
- Send smaller scroll updates to the Mac app while preserving existing schema-1 clients through explicit capability negotiation.
- Improve precision trackpad scrolling, hidden-pane polling, rendering fallback and repeated title/status updates.
- Fix fractional-DPI canvas resizing and reduce repeated web terminal parsing and rendering work.
- Discontinue the Experimental Linux and Windows desktop apps. AkiTTY Web remains the cross-platform browser terminal; the native app is macOS-only.
