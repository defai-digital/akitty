# AkiTTY 1.3.27

## Improvements and fixes

- Make private cursor-position reports respect origin mode and the scrolling region, matching standard cursor-position reports on the main and alternate screens. With a top margin at row 3, a cursor on absolute row 4 now reports row 2 through either query when origin mode is enabled.
- Include the merged ASCII-run terminal writes and bounded PTY read batching. Ordinary text writes operate a row at a time; protocol-sensitive text retains scalar handling. Available short reads coalesce without waiting for more data, with bounded parsing and input/resize fairness. See [performance scope and measurements](../PERFORMANCE.md).
- Rebuild the shared WebAssembly engine and refresh its exact source and artifact provenance.

## Verification

- Reproduced the private cursor-report mismatch before fixing it. Native and actual WebAssembly shared fixtures cover both query forms, origin mode on and off, main and alternate screens, and every byte split.
- The release gate covers Rust, native ABI/PTY and Swift behavior, TypeScript/SDK/Web browser behavior, rebuilt and committed WASM, benchmark smoke checks, shell integration, installer/release tooling and public-file hygiene.

Protocol references: [DEC origin mode](https://vt100.net/docs/vt510-rm/DECOM.html) and [XTerm cursor reports](https://invisible-island.net/xterm/ctlseqs/ctlseqs.html).
