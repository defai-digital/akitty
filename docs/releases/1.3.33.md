# AkiTTY 1.3.33

- Speed up Unicode decoding and grapheme processing with cached character properties and fewer repeat decisions for combining marks and emoji.
- Store up to eight combining marks directly in a cell’s side record. Longer clusters keep the existing sixteen-mark limit.
- Keep pending Metal glyph uploads when a composed frame is skipped during a window or appearance change. Rebuild the affected rows on the next handoff so new glyphs appear correctly.
- Refresh the WebAssembly engine and its source provenance for this release.
