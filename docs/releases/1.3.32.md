# AkiTTY 1.3.32

## Improvements and fixes

- Improve native terminal throughput with bounded PTY read batching, packed cell storage, shared style records, Unicode text runs and bounded grapheme analysis caches.
- Render eligible ASCII terminal frames through a bounded Metal glyph atlas, retaining the software path for complex content and unsupported geometry.
- Preserve glyph uploads and atlas recreation requests across refused frames. Recovery rebuilds every row, preventing missing glyphs and stale content after atlas capacity is reached. Appearance changes also repaint the complete grid.
- Refresh the committed WebAssembly engine and its source provenance for this workspace version.

## Verification

- Reproduced lost glyph uploads and incomplete row recovery before the fix; regressions cover recovery after an established atlas and a refused first frame.
- The full release gate covers Rust, native ABI/PTY/Swift behavior, TypeScript, SDK and web browsers, rebuilt and committed WebAssembly, native traces, shell integration, installer/release tooling and public-file audits.
