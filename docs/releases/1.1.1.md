# AkiTTY 1.1.1

- Open new tabs immediately after the selected tab, starting in the focused pane's
  reported directory when it still exists, with the window's folder as fallback.
- Serve the full download for valid multiple byte ranges when multipart delivery
  is unavailable, while rejecting malformed and reversed range members.
- Reject empty If-Match preconditions before evaluating cache validators or ranges.

Apple Silicon, macOS 14+. AkiTTY Web and the program SDK retain their existing
versions. Shell-reported directories remain untrusted observations and are checked
for an existing local directory before creating the new tab.
