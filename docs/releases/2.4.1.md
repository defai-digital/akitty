# AkiTTY 2.4.1

- Tabs use the focused pane’s title. AkiTTY removes spinner frames from the
  start and end of titles and limits rapid title changes to two per second.
  The latest title appears when the stream of changes stops.
- Returning to a tab restores keyboard focus to the pane you were using.
  Moving a split tab to another window preserves that tab’s focus and restores
  focus to the remembered pane in the tab revealed in the source window.
- Drop a tab on the free title-bar space in another window to add it after
  the existing tabs.
- Click and drag the empty title bar of a background window to move it
  immediately.

The native app requires Apple Silicon and macOS 27.2 or later.
