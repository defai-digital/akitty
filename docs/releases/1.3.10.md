# AkiTTY 1.3.10

- Replace the native and browser terminal engines with the shared AkiTTY-owned Rust VT engine; AkiTTY Web compiles the same engine to WebAssembly.
- Restore character sets, pending single shifts and autowrap alongside the cursor, including after returning from alternate-screen applications.
- Treat zero scroll margins as defaults and ignore equal top/bottom margins without moving the cursor.
- Improve Unicode input, keypad and modifier handling, mouse reporting, terminal colors, cursor rendering and wrapped-line resizing.
- Fix browser terminal buffer inspection, links, subscriptions, scrolling, fractional fitting and WASM file URL loading.
- Reject negative native text ranges and sparse SDK sprite frames.
