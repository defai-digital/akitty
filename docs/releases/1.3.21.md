# AkiTTY 1.3.21

## Local MCP approval bridge

- The bundled companion supports `akitty-agent mcp`, exposing `list_panes` and `request_command` through local stdio.
- Command requests still require Local Agent Requests enabled for that app launch, exact-command native approval, and human reclaim afterward. A dispatch receipt does not establish command completion or success.
- Cancellation and EOF abandon pending approvals. Dispatched commands remain leased and are never automatically retried.
- See [setup and limits](../MCP.md) for client configuration and supported protocol revisions.

## Fixes

- Malformed or contradictory local success receipts now return an MCP error rather than reporting an accepted tool result. Command acceptance, unverified completion, and retained input ownership must be explicit booleans.

## Verification

- Added seven malformed-receipt regression cases with exactly one socket attempt each.
- Verified native approval, denial, cancellation, EOF, exact command bytes, retained leases, bounded stdio, and the complete verification gate.
