# AkiTTY 1.3.29

## Improvements and fixes

- Integrate the native frame-refresh work: visible unfocused panes coalesce automatic refreshes at 30 Hz, while focused panes, recent local input and explicit scroll/selection refreshes remain immediate. Hidden panes keep their existing 4 Hz cadence. Pending work retains a final update and is cancelled on shutdown.
- Add an opt-in native pipeline probe and source-backed measurements of refresh CPU work, snapshots, rasterization, uploads and GPU completion. The probe records no terminal contents and its observers are inactive during ordinary use. See [measurement scope and tradeoffs](../PERFORMANCE.md).
- Soft reset now replaces the active screen's saved cursor position and attributes with defaults. Restoring a cursor after reset no longer revives an old position, colour or graphics character set. Reset itself preserves the current cursor position and screen contents.
- Rebuild the shared WebAssembly engine and refresh source/artifact provenance.

## Verification

- Reproduced the saved-cursor failure before the fix. Native and actual WebAssembly fixtures cover DEC and ANSI save/restore forms, both screens, default rendition and every byte split.
- Refresh regressions cover bursts and final updates, focus and visibility changes, stale deadlines, title/bell delivery and shutdown. The full release gate covers Rust, native ABI/PTY/Swift behavior, TypeScript/SDK/Web browsers, rebuilt and committed WASM, shell integration, installer/release tooling and public-file hygiene.

Protocol reference: [DEC soft terminal reset](https://vt100.net/docs/vt510-rm/DECSTR.html).
