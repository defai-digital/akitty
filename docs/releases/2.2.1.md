# AkiTTY 2.2.1

- Run command-palette search in the Rust core. Earlier matches rank ahead of
  later ones, so typing `s` puts **Split Pane** ahead of commands that only
  match the letter in a keyword.
- Trim pasted search text before applying the query limit and keep Unicode
  text valid at the limit.
- Add setup guides for workspaces, cross-terminal search, profiles, Quick
  Terminal, shortcuts, and agent approvals.
  [User guide](https://github.com/defai-digital/akitty/blob/v2.2.1/docs/USER_GUIDE.md) ·
  [Agent guide](https://github.com/defai-digital/akitty/blob/v2.2.1/docs/AGENT_NATIVE.md#set-up-an-agent)

The native app requires Apple Silicon and macOS 27.2 or later.
