# AkiTTY 2.2.0

- Set up Grok, Muse Code, Kimi Code and AGY from Settings. They can request
  commands in a pane through MCP, and each request needs human approval. Their
  lifecycle hooks let AkiTTY offer to resume a reported conversation.
- Draw supported single-cell color emoji from the Metal glyph atlas. Reuse
  retired atlas textures after the GPU finishes with them, and discard frames
  composed before a renderer reset.
- Use the selected CJK font cascade when caching font layouts and glyph tiles.
- Preserve existing Grok and AGY settings when they conflict with the
  integration, and validate Kimi's hook file before removing its MCP server.

The native app requires Apple Silicon and macOS 27.2 or later.
