# AkiTTY 0.12.2

This maintenance release improves native terminal stability and the separate AkiTTY Web lifecycle.

- Prevent overflow in window pixel-size reports at supported grid and cell sizes, and use default metrics before the host reports a cell size.
- Validate PNG probes using actual header dimensions across file, temporary-file, and shared-memory transports without decoding image pixels.
- Resolve relative image parents and Unicode image placeholders within their owning screen buffer.
- Retarget search when focus moves between panes or tabs, clearing stale highlights and restoring focus to the current owner.
- Preserve a working web terminal when reset allocation fails and retarget selection before freeing the previous terminal.
- Complete web resource cleanup even when addons or link providers throw, reject addon loading after disposal, and suppress delayed link callbacks after disposal.
- Clear selection, scrolling, and hover state during lifecycle transitions; allow FitAddon reuse immediately after disposal; respect read-only input settings for alternate-screen wheel events.

Apple Silicon, macOS 14+. Developer ID signed and notarized, with signed Sparkle updates served through Cloudflare R2. AkiTTY Web remains a separate private source package.
