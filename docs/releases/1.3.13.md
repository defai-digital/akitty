# AkiTTY 1.3.13

Requires macOS 27.2 or later on Apple Silicon. The selection fixes below apply to the separate AkiTTY Web 0.6.3 package.

- Preserve the clipboard on ordinary terminal clicks. A mouse-down anchor without a selected range no longer copies or highlights the clicked character.
- Treat an explicit one-cell API selection as selected, so copy actions and selection queries agree with its text.
- Clear zero-length and negative-length API selections instead of selecting an unintended character.
- Reject non-finite selection coordinates and lengths without replacing an existing selection.
