# AkiTTY 1.3.2

- Read shell state during trusted SDK command approval without consuming rendering snapshots. Pending bell, clipboard and animation observations remain available to the native renderer.
- Finish SDK disposal even when an embedding host's animation cancellation callback throws. Close the client before callbacks run, attempt chrome and title cleanup, and preserve every cleanup error in order.
- Include the native, Web and installer fixes documented in [1.3.1](1.3.1.md), which was not published.

The bundled native app targets Apple Silicon and macOS 14 or later. SDK source version is 0.2.1. AkiTTY Web remains a separate private source package; embedding applications must adopt and qualify its changes independently.
