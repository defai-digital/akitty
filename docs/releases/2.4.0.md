# AkiTTY 2.4.0

- Tabs share the title bar, and the window chrome follows the focused pane's
  theme. Split tabs outline the focused pane.
- Pane status floats over the terminal without changing its size. The
  capsule shows a Reclaim button when an agent holds the input lease.
- The command palette floats over the window and adds tab and pane navigation,
  full-screen controls, and app commands. A dismissed palette can no longer
  dispatch a second command.
- The Dock menu adds profile windows, Quick Terminal, and Agent Overview.
  The Dock icon counts pending approvals.
- Match System follows macOS light and dark appearance. Open panes apply
  Increase Contrast and Reduce Transparency changes immediately. Open tabs
  also follow changes to Reduce Motion for animated status icons.
- New splits are sized before Find searches them.

The native app requires Apple Silicon and macOS 27.2 or later.
