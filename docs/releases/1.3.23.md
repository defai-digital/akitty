# AkiTTY 1.3.23

## Fixes and improvements

- Idle native panes without an agent lease skip redundant control-audit reads once their observed audit sequence is caught up. Event recording continues while local requests are off; leased panes and approval, shutdown, timeline, and export paths still drain the audit.
- AkiTTY Web 0.6.11 stops a link-hover operation when a provider callback resets or disposes the terminal. Stale hover callbacks no longer enter another link or restore a pointer cursor over the replacement terminal.
- Native application lifecycle, windows and panes, tab controls, search, and palette UI now live in focused files within the existing Swift target. The contributor guide maps source ownership, build commands, tests, and generated artifacts.
- Removed the obsolete pnpm dependency lock and attributes for retired engine files. npm remains the package manager; the native ABI, resource locations, and package boundaries are preserved.

## Verification

- Added native regressions for audit draining with a stale idle snapshot while local requests are off, and program-status observation while idle audit reads are skipped.
- Added three Web regressions for reset/disposal from link-hover exit callbacks and reset from a hover-entry callback; all reproduced the defect before the fix.
- The complete verification gate covers Rust, WASM provenance, TypeScript, native ABI/PTY and Swift behavior, Web browser behavior, shell integration, installer/release tooling, and public-file hygiene.
