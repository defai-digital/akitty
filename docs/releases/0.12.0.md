# AkiTTY 0.12.0

This release adds tab controls and persistent search, improves rendering and snapshot performance, and preserves compatibility with existing schema-1 clients.

- Add tab close buttons, middle-click closing, drag reordering, tab context menus, equal widths, and Command-1 through Command-9 selection.
- Keep the find bar open, highlight literal matches, and navigate forward or backward with wrapping. Closing or clearing search removes highlights from every pane, and stale search coordinates no longer highlight unrelated scrolled-in text.
- Serialize snapshots directly and let the native app opt into compact cells and a faster decoder. Existing clients continue receiving keyed schema-1 cells and RGB colour arrays by default.
- Reject malformed UTF-8 and leading-zero numbers in the fast decoder, and bound its traversal of nested fields before falling back to JSONDecoder.
- Batch glyphs that fit their cells and poll at display rate while text or images are changing.
- Reuse unchanged web-terminal rows and preserve complete graphemes and blank cells in its read-only agent API.
- Fix compressed PNG size handling for direct and file transfers, and enforce the 512-frame animation limit.
- Use a tab-hover colour that builds with both the local SDK and CI's Xcode SDK.

Apple Silicon, macOS 14+. Developer ID signed and notarized, with signed Sparkle updates served through Cloudflare R2.
