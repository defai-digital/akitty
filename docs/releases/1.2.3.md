# AkiTTY 1.2.3

- Keep Kitty graphics images in scrollback when reverse index or scroll-down moves viewport text down.
- Clamp graphics scroll distances to the terminal scroll region, so oversized scroll-up commands retain images alongside their text in history.
- Add regressions for reverse index, scroll-down and oversized scroll-up commands.

Apple Silicon, macOS 14+. Distribution requires Developer ID signing, notarization and signed Sparkle updates. AkiTTY Web remains a separate private source package.
