# AkiTTY 2.4.2

- Preserve cursor positions around wide characters when resizing a terminal.
- Keep images in the main screen's scrollback when a program clears history from
  the alternate screen.
- Route Control chords to the macOS input method during composition. Programs
  using Kitty keyboard reporting receive releases for keys pressed before
  composition started. Keys handled by the input method produce no unmatched
  release reports.
- Add a documentation index and move historical notes to the archive.

The native app requires Apple Silicon and macOS 27.2 or later.
