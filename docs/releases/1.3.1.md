# AkiTTY 1.3.1

- Bound combining marks, forwarded OSC bodies and terminal reply backlogs so malformed or unread terminal traffic cannot grow memory without limit or unnecessarily end a session. Enforce a 512 MiB image budget across native sessions while retaining the per-session limits.
- Preserve pending bell, clipboard and animation observations when a snapshot exceeds the response limit. Read shell/control summaries without consuming a rendering snapshot, and keep pixel-size updates aligned with the latest queued grid resize.
- Keep failed command dispatches separate from later untrusted shell-completion reports. Avoid unnecessary snapshot invalidation for rejected control operations that changed neither state nor audit history.
- Move routine local event writes off the main thread, retain ordered durable writes before managed dispatch, and avoid recording unchanged program-state counts on every progress update. Resolve approval requests when their parent window closes.
- Reduce hidden-pane raster work, bound renderer colour caching and retain the correct tab sprite for the pane reporting activity. Sanitize blank, padded or invisible update-version labels before showing a reminder.
- Harden installer replacement and cancellation: preserve the previous app on a failed replacement, stop and reap the inner installer on cancellation, and remove an abandoned lock only when it still belongs to that exact child.
- Fix Web source-package lifecycle and interaction bugs: settle queued fits, detach disposed selection listeners, discard stale asynchronous link results, and translate URL offsets after emoji into terminal-cell columns. Bound agent-tool titles and reject undeclared tool arguments.
- Stabilize approval-deadline regression tests with a controlled monotonic clock while preserving the production deadline and real-time timeout behavior.

Apple Silicon, macOS 14+. The native download is Developer ID signed and notarized, with signed Sparkle updates. AkiTTY Web remains a separate private source package; embedding applications must adopt and qualify these source changes independently. Agent reports and shell observations remain unverified, and the local request interface still requires human approval for every command.
